## Mejora de nitidez 3.3.2
Reemplazar el archivo `mapa-3.3.webp` por el WebP optimizado 4096 × 3142, manteniendo **exactamente el mismo nombre**. No modificar coordenadas de ciudades: el motor sigue usando 2048 × 1571 como espacio lógico. Al publicar el archivo aumentado, la URL de la aplicación añade `?v=3.3.2` para renovar la caché. La resolución superior se ha interpolado desde el PNG 2048 × 1571, por lo que suaviza la ampliación pero no inventa detalles originales.
